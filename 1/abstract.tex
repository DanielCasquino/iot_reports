This report documents Lab~1 on circuit simulation and Arduino implementation. A diode-loaded Wheatstone bridge is analyzed in Falstad and a potentiometer-tuned bridge plus LED panel in Tinkercad; five-branch LED circuits, a non-blocking four-LED timing system with instantaneous button reversal, and a non-blocking $4\times4$ matrix-keypad access system with serial feedback are then implemented on Arduino MEGA2560. Simulations, measurements, videos, and Tinkercad sources are referenced throughout.
