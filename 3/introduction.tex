\IEEEPARstart{T}{his} laboratory approaches the connection between data acquisition on an ESP32 and message distribution using MQTT. The guide organizes experiments in connectivity, telemetry, control and serial integration \cite{guia}.

\subsection{Theoretical Framework}
MQTT uses the publisher--subscriber model: a client publishes to a topic, and the server distributes messages according to subscriptions.
MQTT 3.1.1 requires an ordered, bidirectional transport, like TCP. Its QoS level~0 offers delivery at most once; it does not guarantee that every message will reach the receiver \cite{mqtt311}. Therefore, simply observing a connection is not enough to quantify message loss or receipt of sensor readings.

In the Arduino-ESP32 API, \texttt{analogRead} returns a raw, uncalibrated ADC code, while \texttt{analogReadMilliVolts} provides a calibrated result in millivolts \cite{esp32adc}. An ADC code obtained from a divider with an LDR does not directly equate to illuminance in lux. The relation
with illumination requires characterizing the sensor, circuit, and reference conditions; this conversion is not performed here.

PubSubClient 2.8 selects MQTT 3.1.1 by default. Its overload \texttt{publish(topic,payload)} constructs a message without retention and without QoS bits~1/2; \texttt{loop()} handles client communication \cite{pubsub28}. These properties describe the library and allow interpretation of the CP2 sketch; they do not replace a receiver capture.

\subsection{Research Background and Positioning of This Work}
Hunkeler, Truong, and Stanford-Clark proposed MQTT-S to extend publisher--subscriber communication to sensor networks with energy and bandwidth constraints \cite{mqtts}. The prior work shows the adaptation of the model to other transport mechanisms. The present lab uses MQTT over a WiFi/TCP connection; it does not implement MQTT-S or reproduce its evaluations. This brief review provides relevant background and a reference standard; it is not intended to be a comprehensive review of the state of the art.
